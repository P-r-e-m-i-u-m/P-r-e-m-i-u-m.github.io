# Syed Abdul Aman

Personal portfolio website: [p-r-e-m-i-u-m.github.io](https://p-r-e-m-i-u-m.github.io/)

A small, static portfolio built with plain HTML, CSS, and JavaScript. It presents the work and interests already shown on the website.

## Project structure

```
.
└── index.html
```

## Run locally

No package installation or build step is required.

```bash
python -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).

## Update the site

Edit `index.html` and preview the page locally before publishing. Keep project descriptions and links consistent with their source repositories, and avoid adding unverified claims or metrics.

## Publishing

The site is hosted with GitHub Pages from this repository. Changes merged into the configured publishing source are deployed by GitHub Pages.

## Technology

- Semantic HTML
- CSS
- Vanilla JavaScript
- GitHub Pages
